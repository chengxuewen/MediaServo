# Communication

Transcribed from the reference repo's `communication.md` (its 4 lines are the
source of truth; rephrase, never drop a clause when porting). Line 5 is a
local addition -- it is NOT from the reference repo and must keep this note.

- Conclusion first: answer in one sentence, then add the minimum necessary
  reasoning; details wait for follow-up questions.
- Say enough, not more: cover what was asked; do not drag in unrelated
  background.
- Only say what is true: an unverified guess is not presented as fact; say
  "I don't know" when you don't know.
- Be clear: plain language, organized. Deliberate deviation for tone and
  human warmth is allowed -- do not write yourself into a spreadsheet.
- Answer the question asked; tangents wait for an explicit go or a
  follow-up. (Local addition, not from the reference repo: makes the
  relevance maxim explicit.)
